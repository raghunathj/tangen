# Building a Tangen project

**Use the `tangen-developer` skill.** It is the procedure for any Tangen task,
including building a project from an empty directory, and it does not go stale
the way a second copy of it would.

Building a whole project is not a different procedure from changing one, only a
longer one: inspect what exists, find the pages that own each capability you
need, plan, implement with public surfaces, and prove each piece works before
moving to the next.

Start at **https://docs.tangen.app/llms.txt** and follow its "Start here" list.
The Quick Start takes you from nothing to a running query; the Enterprise
Website tutorial builds a complete multilingual site and is the best model for
how the capabilities fit together.

This file used to carry its own recipes. They were removed because they were a
second, unverified copy of documentation that is checked against the running
product - and when the two disagreed, nobody could tell which was right.
