# Learn

Sequential tutorials that build something real, from an empty directory to a running site.

- **[Quick Start](/learn/quick-start)** - about 15 minutes. Create a project,
  define one content type, publish an article, query it with the SDK, and render
  it. The smallest complete loop, and the fastest way to know whether Tangen
  fits.

- **[Build the Enterprise Website](/learn/enterprise-website)** - the long
  form, in fourteen chapters. A realistic multilingual B2B site: eight content
  types, a page builder an editor can use, media, three languages, two forms, an
  automation that routes demo requests, and three deployments ending in a
  production boot.

Take the Quick Start first if you have never used Tangen. The Enterprise Website
assumes you have seen the loop once, and then stops assuming anything.

[Build with Tangen](/build) covers the same ground as individual tasks when you
want one answer rather than a sequence.
