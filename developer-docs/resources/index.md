# Resources

Material that supports the documentation without being part of a learning path.

## Examples

| example | what it shows | proven |
|---|---|---|
| **[Enterprise Website](/learn/enterprise-website)** | the full product: 8 content types, blocks, Globals, media, TangenQL, en/fr/de, Forms, Flow, three deployments, SEO | built from its own documentation in a clean external project |

The Enterprise Website is both a reference application and a **fourteen-chapter
tutorial**. Start at [Build the Enterprise
Website](/learn/enterprise-website); the code is
`examples/enterprise-website` in the Tangen repository.

Three further examples exist in the Tangen repository and have not yet been
rebuilt from publication-shaped artifacts. They are not listed here until they
have been, because an example that does not run costs a reader more than it
gives them.

## Glossary

The terms this documentation uses precisely - and the ones it deliberately
avoids - are decided. A glossary page will live here; until it does, the
decisions are recorded with the documentation planning material rather than
linked from a page that does not exist yet.
